Quantish Agent

AI-powered agent for building trading bots on Polymarket. Combines coding tools (filesystem, shell, git) with trading tools (orders, positions, balances) powered by Claude AI.

$ npm install -g @quantish/agent
$ quantish init
✓ Anthropic API key configured
✓ Quantish wallet created
Ready to trade!
$ quantish

Get Started View on GitHub

Features

🤖 Claude AI Powered

Uses Claude Sonnet, Opus, or Haiku. Switch models on the fly with /model.

💰 Real Cost Tracking

See exactly what you're spending per API call with accurate token counting.

📊 Polymarket Trading

Place orders, check positions, manage your portfolio through natural language.

💻 Full Coding Tools

Read/write files, run commands, git operations - build bots directly.

🔄 Background Processes

Run long-running tasks in background with live output tracking.

🧠 Context Management

Smart token optimization with /compact to summarize long conversations.

How It Works

Quantish connects to two backend services:

Discovery MCP

Free, read-only access to prediction market data across Polymarket, Kalshi, and more. Uses an embedded public API key - no setup required.

Trading MCP

Your personal trading wallet for Polymarket. Created during quantish init with your own API key. Gasless trading - Polymarket covers all fees.
