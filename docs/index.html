Quantish Agent

AI-powered agent for trading on Polymarket and Kalshi. Combines coding tools (filesystem, shell, git) with trading tools (orders, positions, balances).

🆕 Two Versions Available

V1 (quantish) - OpenRouter/Anthropic powered, built from scratch. Best for custom bots.
V2 (quantish2) - Gemini powered, native MCP integration. Best for app building.

See comparison below →

# Install V1 (OpenRouter/Anthropic)
$ npm install -g @quantish/agent
$ quantish init && quantish
 
# Install V2 (Gemini-powered)
$ npm install -g @quantish/agent-v2
$ quantish2

Features

🤖 Multi-Provider AI

Use Claude (Anthropic) or 100+ models via OpenRouter (GLM-4.7, MiniMax, DeepSeek).

💰 Real Cost Tracking

See exactly what you're spending per API call with accurate token counting.

📊 Multi-Platform Trading

Trade on Polymarket (Polygon) and Kalshi (Solana via DFlow) through natural language.

💻 Full Coding Tools

Read/write files, run commands, git operations - build bots directly.

💾 Session Persistence

Save and resume conversations with /save, /resume, /sessions commands.

⚡ Queued Input

Type while agent is working, queue messages. Press Esc to interrupt and send.

How It Works

Quantish connects to three backend services:

Discovery MCP

Free, read-only access to prediction market data across Polymarket, Kalshi, and Limitless. Uses an embedded public API key - no setup required.

Polymarket MCP

Your personal trading wallet on Polygon. Created during quantish init. Gasless trading - Polymarket covers all fees.

Kalshi MCP

Trade on CFTC-regulated Kalshi markets via DFlow on Solana. Create an account by asking the agent "Create a Kalshi account for me".
