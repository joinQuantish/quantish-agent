Self-Hosting

Run your own Trading MCP servers for full control over your wallet keys and infrastructure. We provide packages for both Polymarket (Polygon) and Kalshi (Solana via DFlow).

⚡ Why Self-Host?
  • Full Control - Own your private keys completely
  • Custom Logic - Add your own trading strategies
  • Privacy - No third-party access to your trades
  • Compliance - Meet regulatory requirements

Configure Custom Server URLs

Configure the CLI to point to your own Trading MCP servers:

Environment Variables

# Polymarket server
export MCP_SERVER_URL=https://your-polymarket-server.com/mcp

# Kalshi server
export KALSHI_MCP_URL=https://your-kalshi-server.com/mcp

Config File

Edit ~/.quantish/config.json directly:

{
  "anthropicApiKey": "sk-ant-...",
  "quantishApiKey": "your-polymarket-key",
  "kalshiApiKey": "your-kalshi-key",
  "mcpServerUrl": "https://your-polymarket-server.com/mcp",
  "kalshiMcpUrl": "https://your-kalshi-server.com/mcp",
  "model": "claude-sonnet-4-5-20250929"
}

Server Requirements

Your self-hosted Trading MCP server must implement the following:

Endpoint

POST /mcp/execute
Content-Type: application/json
X-API-Key: <user-api-key>

Request Format (JSON-RPC 2.0)

{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "get_balances",
    "arguments": {}
  },
  "id": 1
}

Response Format

{
  "jsonrpc": "2.0",
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"success\": true, \"data\": {...}}"
      }
    ]
  },
  "id": 1
}

Required Tools

Your server should implement at minimum:

Tool Description
get_balances Return wallet USDC and collateral balances
get_positions Return current market positions
place_order Submit buy/sell orders to Polymarket
cancel_order Cancel an open order
get_orders List open/filled orders

Polymarket Server (@quantish/polymarket-server)

Self-host a Polymarket MCP server for trading on Polymarket via Polygon:

$ git clone https://github.com/joinQuantish/polymarket-mcp
$ cd polymarket-mcp && npm install

Source code: github.com/joinQuantish/polymarket-mcp

Polymarket Server Environment Variables

Variable Description
DATABASE_URL PostgreSQL connection string
ENCRYPTION_KEY 64-character hex string for wallet encryption
ENCRYPTION_IV 32-character hex string for encryption IV
POLYGON_RPC_URL Polygon RPC endpoint (e.g., Alchemy, Infura)

Generate Encryption Keys

$ node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
# Use output for ENCRYPTION_KEY
$ node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
# Use output for ENCRYPTION_IV

Setup and Run

$ npm run db:generate
$ npm run db:push
$ npm start
Polymarket MCP server running on http://localhost:3000

Required Environment Variables

Variable Description
DATABASE_URL PostgreSQL connection string
POLYMARKET_API_KEY Your Polymarket Builder API key
POLYMARKET_API_SECRET Your Polymarket Builder API secret
POLYMARKET_PASSPHRASE Your Polymarket Builder passphrase
ENCRYPTION_KEY 32-byte hex key for wallet encryption

Getting Polymarket Builder Credentials

To run your own Trading MCP server, you need Polymarket Builder API credentials:

  1. Apply via the Polymarket Developer Docs
  2. Complete the application process (typically 1-2 weeks)
  3. Once approved, you'll receive API key, secret, and passphrase
⚠️ Security Note

Never commit your Polymarket credentials or encryption keys to version control. Always use environment variables or a secrets manager.

Kalshi Server (@quantish/kalshi-server)

Self-host a Kalshi MCP server for trading on Kalshi via DFlow on Solana:

$ npm install @quantish/kalshi-server

Source code: github.com/joinQuantish/kalshi-mcp

⚠️ DFlow API Key Required for Self-Hosting

DFlow access is not permissionless. To self-host a Kalshi MCP server:

  1. Contact the DFlow team directly at dflow.net
  2. Request API access for your organization
  3. Once approved, add DFLOW_API_KEY to your environment variables

Using Quantish's public servers? No DFlow key needed - we handle this for you. Just use the default MCP endpoints.

Kalshi Server Environment Variables

Variable Description
DATABASE_URL PostgreSQL connection string
ENCRYPTION_KEY 64-character hex string for wallet encryption
JWT_SECRET Secret for API key generation
DFLOW_API_KEY DFlow API key (must be obtained from DFlow team - see note above)
SOLANA_RPC_URL Solana RPC endpoint (e.g., Helius, Quicknode)

Generate Encryption Key

$ node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
a1b2c3d4e5f6... (64 characters)

Testing Your Server

Test that your server is working correctly:

$ curl -X POST https://your-server.com/mcp/execute \
-H "Content-Type: application/json" \
-H "X-API-Key: your-api-key" \
-d '{"jsonrpc":"2.0","method":"tools/call","params":{"name":"get_balances","arguments":{}},"id":1}'

Expected response:

{
  "jsonrpc": "2.0",
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"success\":true,\"data\":{\"usdc\":\"100.00\",\"collateral\":\"0.00\"}}"
      }
    ]
  },
  "id": 1
}
