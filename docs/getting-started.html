Getting Started

Get up and running with Quantish Agent in 5 minutes.

Prerequisites

  • Node.js 18+ - Download here
  • LLM API Key - Either:
    • Anthropic API Key (Claude models)
    • OpenRouter API Key (100+ models)

Step 1: Install

$ npm install -g @quantish/agent

Or run directly with npx:

npx @quantish/agent

Step 2: Initialize

Run the setup wizard to configure your API keys:

$ quantish init
 
🔐 Setting up Quantish Agent
 
Choose your LLM Provider:
1. Anthropic (Claude models)
2. OpenRouter (100+ models)
> 2
✓ LLM Provider set to openrouter
 
Enter your OpenRouter API key:
✓ OpenRouter API key saved
 
Creating your Quantish wallet...
✓ Wallet created!
 
Setup complete! Run 'quantish' to start.

What happens during init?

  1. LLM Provider - Choose Anthropic (Claude) or OpenRouter (100+ models)
  2. API Key - Stored locally for your chosen LLM provider
  3. Polymarket Wallet - A Polygon wallet is created via the Quantish Signing Server
  4. Kalshi Account - Optional: Create a Solana wallet for Kalshi trading
About the Signing Servers

Polymarket: Gasless trading on Polygon via the Quantish Signing Server. Polymarket covers all transaction fees.

Kalshi: Trading on Solana via DFlow protocol. Small SOL fees (~0.01 SOL per trade).

Both wallets are non-custodial - you can export your private keys anytime.

To trade on Kalshi, ask the agent to create an account:

Step 5: Fund Your Wallets

To trade on Polymarket, you need USDC in your wallet. Ask the agent for your deposit address:

You: get my deposit address

Deposits are automatically converted to USDC.e for trading.

Environment Variables

You can also set keys via environment variables:

Variable Description
ANTHROPIC_API_KEY Anthropic API key (for Claude models)
OPENROUTER_API_KEY OpenRouter API key (for 100+ models)
QUANTISH_API_KEY Polymarket trading API key
KALSHI_API_KEY Kalshi trading API key
MCP_SERVER_URL Optional: Custom Polymarket MCP server URL
KALSHI_MCP_URL Optional: Custom Kalshi MCP server URL
EXA_API_KEY Optional: Exa AI for better web search 
# For Anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

# OR for OpenRouter
export OPENROUTER_API_KEY="sk-or-..."

# Trading keys
export QUANTISH_API_KEY="qtsh_..."  # Polymarket
export KALSHI_API_KEY="kalshi_..."  # Kalshi (optional)
quantish

Configuration File

Config is stored in ~/.quantish/config.json:

{
  "provider": "openrouter",
  "openrouterApiKey": "sk-or-...",
  "quantishApiKey": "qtsh_...",
  "mcpServerUrl": "https://quantish-sdk-production.up.railway.app/mcp",
  "model": "z-ai/glm-4.7"
}
